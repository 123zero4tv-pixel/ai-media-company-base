# AI Media Company — Base Architecture

Architecture-first foundation for the AI Media Company web project.

Principles:
- AI Media Company only; no trading-company architecture.
- Specialized AI employees with distinct responsibilities.
- Structured collaboration through tasks and handoffs.
- Shared company knowledge plus department/private working memory.
- Evidence, confidence, assumptions, decisions, approvals, and audit logs are first-class data.
- Build the company core first; Pixel Office later.

Initial V1:
Research -> Idea -> CEO Decision -> Writer -> QA -> Publish-ready -> Analytics.
