# V1 Build Plan

1. Foundation: web shell, database, company/agent/task models, audit log, evidence, permissions.
2. Core AI: CEO, Research, Idea, Writer, QA, Analytics.
3. Content pipeline: Research -> Idea -> Decision -> Writing -> QA -> Analytics.
4. Production: Producer, Visual, Video, Publisher.
5. Automation: scheduler, task queue, workers, retry/error handling, human approval gates.
6. Pixel Office: isometric office, agent characters, real status/task visualization, click-to-interrogate UI.

Do not implement Pixel Office before the core workflow is functional.
